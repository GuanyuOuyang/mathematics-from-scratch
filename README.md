# Math from Scratch

### What is this?

I'm a incoming CS PhD student who eventually realized that
"I'll just look it up when I need it" does not scale.

So this repo is my attempt to relearn math properly,
from the beginning, with proofs, exercises, and lots of confusion.

### Why I'm doing this

I want to build a sense for rigorous mathematical reasoning,
not just the ability to write things that *look* like proofs.

At some point I noticed an uncomfortable gap:
I could write down arguments where every step felt reasonable,
yet I had no solid way to tell why the final conclusion
had to be correct, or whether it actually was.
Understanding a proof and being able to judge its correctness
turned out to be very different skills.

So this repo is me trying to close that gap.
I’m starting from definitions again,
writing things out in full,
and only trusting arguments I can personally justify.
The goal isn’t speed or coverage,
but eventually being able to tell — on my own —
when a proof is right, when it’s wrong,
and why.

This is written as if I’m at the beginning,
even though I know better now how long the road actually is.
